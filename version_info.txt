# Ressource de version Windows pour TempoFacture.exe (PyInstaller), reference
# par `version='version_info.txt'` dans l'appel EXE(...) de TempoFacture.spec.
#
# Correctif de l'audit expert (constat I4) : sans ce fichier, l'onglet
# "Details" des proprietes Windows de l'executable distribue n'affichait
# AUCUNE metadonnee (FileVersion/ProductVersion a 0.0.0.0, CompanyName/
# FileDescription/LegalCopyright vides) - un detail de professionnalisme,
# et un facteur mineur pouvant influencer certaines heuristiques
# antivirus (lie a I3, hors perimetre de ce correctif). Meme demarche que
# pour "Coffre" (autre outil de la meme suite), voir Coffre/version_info.txt.
#
# IMPORTANT : filevers/prodvers et les chaines FileVersion/ProductVersion
# ci-dessous doivent etre mis a jour EN MEME TEMPS que APP_VERSION dans
# gui.py a chaque nouvelle version (pas de generation automatique - ce
# fichier est lu par PyInstaller via un mini-parseur dedie, pas par
# l'interpreteur Python, il ne peut donc pas importer gui.py directement).

    filevers=(1, 2, 0, 0),
    prodvers=(1, 2, 0, 0),
    mask=0x3f,

    OS=0x40004,
    fileType=0x1,
    subtype=0x0,
    date=(0, 0),
    ),
  kids=[

      ]),

  ]
